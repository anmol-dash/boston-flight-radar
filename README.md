# Boston Flight Radar

A self-hosted, FlightRadar24-style live traffic display for a kiosk screen (built for a Raspberry Pi running Chromium in kiosk mode). It shows live aircraft over Boston from [adsb.lol](https://adsb.lol/) with each flight's origin and destination resolved via [adsbdb](https://www.adsbdb.com/), live marine traffic in Boston Harbor from [AISStream.io](https://aisstream.io/), and a fixed location marker, all rendered on a dark Esri basemap with Leaflet. `radar_server.py` is a small dependency-light Python HTTP server that proxies the adsb.lol and adsbdb APIs (both block cross-origin browser requests) and runs a background thread that maintains the AISStream websocket connection, exposing simple local JSON endpoints that `radar/radar.html` polls.

To run it: install `websocket-client` (`pip3 install --user websocket-client`), set the `AISSTREAM_API_KEY` environment variable to a free key from aisstream.io (vessel tracking is skipped if unset), and start the server with `python3 radar_server.py` — it listens on `127.0.0.1:8765` by default. Point a browser (ideally Chromium in `--kiosk` mode) at `http://127.0.0.1:8765/` to see the display. The bounding boxes, map center/zoom, and the "my location" marker are hardcoded for the Boston area in `radar_server.py` and `radar/radar.html` — adjust the latitude/longitude constants in both files to point it at a different city.
